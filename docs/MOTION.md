# Diretrizes de Movimento e Animação — Projeto Nandinha

> **Status:** Aguardando Estágio 2 e 3.

## Objetivo deste Documento

Definir curvas de aceleração (easings), durações padrão, timelines do Anime.js e coreografia de entrada dos elementos.

## Conteúdo a ser preenchido:

1. Easing functions padrão.
2. Duração de transições (Fast: 150ms, Normal: 300ms, Slow: 500ms, Narrative: 1200ms).
3. Coreografia de entrada de tela.
4. Regras para `prefers-reduced-motion`.
