# Design System — Projeto Nandinha

> **Status:** Aguardando Estágio 3.

## Objetivo deste Documento

Especificar a linguagem visual, escala tipográfica, paleta cromática e regras de acessibilidade estética da aplicação.

## Conteúdo a ser preenchido:

1. Paleta de cores oficial (Primária, Acentos, Superfícies, Textos).
2. Escala tipográfica e pesos.
3. Raio de bordas e elevações (sombras).
4. Grid e espaçamentos (sistema de 4px/8px).
5. Estados interativos (Hover, Active, Focus-Visible, Disabled).
